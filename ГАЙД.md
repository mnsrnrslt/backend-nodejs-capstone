# GiftLink: что тебе сделать руками

Код в архиве готов полностью. Тебе остаётся сделать то, что требует твоих аккаунтов
(GitHub, IBM Skills Network), а потом собрать скрины и выводы для формы.
Займёт примерно 1–2 часа, если ничего не сломается.

---

## Шаг 1. Залить проект на GitHub (с твоего Mac)

1. На github.com нажми **New repository**. Имя **строго** `fullstack-capstone-project`,
   тип **Public**. Галочки README / .gitignore **не ставь**, репа должна быть пустой.
2. Распакуй архив и в терминале выполни:

```bash
cd fullstack-capstone-project
git init                         # превращаем папку в git-репозиторий
git add .                        # добавляем все файлы в индекс (staging)
git commit -m "GiftLink capstone project"
git branch -M main               # называем ветку main (workflow слушает именно её)
git remote add origin https://github.com/<ТВОЙ_НИК>/fullstack-capstone-project.git
git push -u origin main          # отправляем; -u запоминает связку локальной и удалённой ветки
```

Если GitHub попросит пароль: обычный пароль не подойдёт, нужен **Personal Access Token**
(Settings → Developer settings → Personal access tokens). Проще поставить `brew install gh`
и выполнить `gh auth login`, тогда авторизация работает сама.

> ⚠️ Файлы `.env` в репу не попадут, их отсекает `.gitignore`. Так и задумано: секреты не коммитят.

## Шаг 3. CI/CD → Задача 18

После `git push` GitHub Actions запустится сам.

1. Открой вкладку **Actions** и дождись зелёной галочки (2–3 минуты, сборка React небыстрая).
2. Открой run → джоб **Lint JavaScript Files** → раскрой все шаги → скопируй лог.
   То же сделай для **Build Client**.
3. Вставь в задачу 18.

Если run красный, скопируй ошибку и кинь мне.

## Шаг 4. Запуск в IBM Skills Network → Задачи 3, 13–17

Открой любую лабу курса с кнопкой **Open Tool / Launch Cloud IDE**.

### 4.1 Клонируй репу

```bash
cd /home/project
git clone https://github.com/<ТВОЙ_НИК>/fullstack-capstone-project.git
cd fullstack-capstone-project
```

### 4.2 Подними MongoDB

Слева **Skills Network Toolbox** → **Databases** → **MongoDB** → **Create**.
Когда база стартует, там будут **хост** и **пароль**.

> Если плагина нет, подними базу в Docker прямо в терминале:
> `docker run -d --name mongo -p 27017:27017 mongo:6`
> Тогда `MONGO_URL=mongodb://localhost:27017`.

### 4.3 Настрой и запусти бэкенд

```bash
cd giftlink-backend
cp .env.example .env     # копируем шаблон конфига
nano .env                # вписываем MONGO_URL (хост + пароль из 4.2) и любой длинный JWT_SECRET
npm install              # ставим зависимости из package.json
npm run import           # импорт 16 подарков в базу giftdb.gifts
```

➡️ **Задача 3:** вывод `npm run import`, там будет строка `Inserted documents: 16`. Скопируй весь вывод.
(Импорт нужно запускать на **пустой** базе. При повторном запуске скрипт пишет «already exist»
и ничего не вставляет.)

```bash
npm start                # сервер на порту 3060, терминал оставь открытым
```

### 4.4 curl-тесты → Задачи 13–17

Открой **новый терминал** (бэкенд должен работать в первом):

```bash
cd /home/project/fullstack-capstone-project
bash scripts/curl-tests.sh
```

Скрипт создаст папку `submission/` с файлами `mainpage`, `register`, `login`, `item_detail`,
`search_item`. В каждом лежит команда и её вывод. Открой файл, скопируй содержимое и вставь
в соответствующую задачу:

| Файл | Задача |
|---|---|
| `mainpage` | 13 |
| `register` | 14 |
| `login` | 15 |
| `item_detail` | 16 |
| `search_item` | 17 |

> Регистрация проходит **один раз**. Если запустишь скрипт повторно, получишь
> `Email id already exists`. Чтобы повторить, смени почту: `EMAIL=new@mail.com bash scripts/curl-tests.sh`.

## Шаг 5. Деплой фронта на Code Engine → Задача 12

1. **Skills Network Toolbox** → **Cloud** → **Code Engine** → **Create Project**.
   Затем нажми **Code Engine CLI**, откроется терминал, уже залогиненный в IBM Cloud.
2. В этом терминале:

```bash
cd /home/project/fullstack-capstone-project/giftlink-frontend

# собираем образ; -t задаёт имя/тег, $SN_ICR_NAMESPACE (твой namespace в IBM registry) уже задан в лабе
docker build -t us.icr.io/$SN_ICR_NAMESPACE/giftwebsite .

# отправляем образ в IBM Container Registry
docker push us.icr.io/$SN_ICR_NAMESPACE/giftwebsite

# создаём приложение в Code Engine из этого образа, порт 9000 (на нём слушает server.js)
ibmcloud ce application create --name giftwebsite \
  --image us.icr.io/$SN_ICR_NAMESPACE/giftwebsite \
  --registry-secret icr-secret --port 9000
```

3. В конце команда выведет URL вида `https://giftwebsite.xxxx.codeengine.appdomain.cloud`.
   Открой его в браузере.
4. **Задача 12:** скрин, на котором видны **URL в адресной строке**, заголовок **GiftLink**,
   слоган и кнопка **Get Started**. Сохрани как `deployed_landingpage.png`.

> Если `--registry-secret icr-secret` выдаст ошибку, посмотри в лабе модуля 4, как там
> называется секрет. Бывает, что его нет вообще, тогда просто убери этот флаг.
> Для скрина лендинга бэкенд не нужен: эта страница статическая.
